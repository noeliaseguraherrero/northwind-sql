## Cómo reproducir este trabajo

1. Abrir pgAdmin y crear una nueva base de datos, por ejemplo:

   ```sql
   CREATE DATABASE northwind;
   ```

2. Conectarse a la base de datos recién creada.

3. Abrir el Query Tool y cargar el script de creación/carga de datos incluido en este repositorio (`nombre_del_script.sql`).

4. Ejecutar el script completo para crear las tablas e insertar los datos.

5. Una vez cargada la base de datos, abrir el archivo `respuestas.md` para consultar los enunciados y las consultas SQL desarrolladas.
